유지보수 런북

프로젝트 루트에서 collector/.venv 를 활성화한 뒤 실행합니다. PYTHONUTF8=1 을 설정하세요 (한국어 Windows).

1. 카테고리 추가
config/categories.yaml 에 항목을 추가한다 — 이름·키워드·exclude·discovery_queries(채널검색)·discovery_queries_niche(인기영상). 코드 수정은 필요 없다. 중복 키를 넣으면 테스트가 잡는다.
python -m pytest tests/test_config.py
2. 새 카테고리만 시드 발굴
--only 를 반드시 쓴다 — 전체 재발굴은 카테고리당 700u 씩 쿼터를 다시 태운다. 기존 카테고리는 파일 값을 그대로 유지한다.
python -m jobs.bootstrap_seeds --only <category_id>
3. DB 에 카테고리 반영
YAML 이 단일 진실이고 DB 테이블은 사본이다. 웹이 카테고리 이름을 읽으려면 동기화가 필요하다.
python -m jobs.sync_config
4. RSS 실검증 (쿼터 0)
채널 최신 15개 영상 제목으로 카테고리 적합도를 판정한다. 탈락은 삭제 대상이 아니라 검토 대상이다 — 키워드가 부족해 놓친 경우가 섞인다.
python tools/verify_seeds.py --only <category_id>
python tools/verify_seeds.py --write # 검토 후 탈락분 제거
5. 검토·상황판 갱신
생성 후 아티팩트로 게시하면 링크가 유지된다.
python tools/gen_seeds_review.py
python tools/gen_admin.py
python tools/gen_progress.py
6. 보관 정책 집행
YouTube ToS — 수집 데이터는 30일 내 갱신 또는 삭제. 수집 cron 이 매번 함께 실행한다.
python -m jobs.purge --dry-run
python -m jobs.purge
